# GRACE — glossaire technique EN ↔ FR

Référence lab pour l’i18n (`client/src/i18n`). Équivalents métier sûreté / risque, pas des calques.

| English | Français | Note |
|---------|----------|------|
| Assessment | Analyse de risque | Pas « évaluation » seule — contexte SRA |
| Asset | Actif | CMDB sûreté |
| Cluster | Cluster | Conservé (terme produit) |
| Threat | Menace | Scénario 3-A |
| Countermeasure | Contre-mesure | Mesure de maîtrise / SPP |
| Action plan | Plan d’action | Mitigation REDUCE |
| Survey | Questionnaire | Preuves terrain |
| Survey scope | Périmètre questionnaire | Jeu approuvé |
| Template package | Pack de modèles | Lot sectoriel |
| Template | Modèle | Catalogue réutilisable |
| Likelihood | Vraisemblance | Pas « probabilité » (échelle CSMP) |
| IRV | IRV | Inherent Risk Value / risque inhérent |
| TEAR | TEAR | Transférer / Éliminer / Accepter / Réduire |
| ALARP | ALARP | Risque résiduel justifié |
| 3-A | 3-A | Adversaire–Actif–Action |
| PPS | SPP | Système de protection physique |
| Review queue | File de revue | Circuit d’approbation |
| Audit log | Journal d’audit | Instantanés |
| Lead assessor | Chef d’évaluation | Rôle |
